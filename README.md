# Rayhan X-Ray — iPad & iPhone app (demo)

SwiftUI app for iPadOS / iOS 26 with Liquid Glass, Live Activities (Dynamic Island), widgets, Control Center controls and Siri shortcuts.
It runs on built-in demo data (invented patients, synthetic X-rays) saved on the device; it is not connected to the clinic PCs yet.

## Get the app
Every push builds an unsigned `Rayhan.ipa` on GitHub's Macs (see *Releases*).

1. Download `Rayhan.ipa` from the latest release.
2. Open **Sideloadly** on your PC, plug in the iPad, drop the IPA in, enter your Apple ID, Start.
3. On the iPad: Settings → General → VPN & Device Management → trust your Apple ID. Turn on Developer Mode if asked.

With a free Apple ID the app works for 7 days, then install it again the same way (your data stays).

## Build it yourself
`brew install xcodegen && xcodegen generate && open Rayhan.xcodeproj` (Xcode 26).

Fonts: Inter (SIL Open Font License, see `Resources/Fonts/Inter-LICENSE.txt`). X-ray images in `Resources` are generated by `tools/make_xrays.py` and contain no patient data.
